# Code of conduct

Keep project discussions respectful, constructive, and focused on the work. Welcome people with different backgrounds and levels of experience. Give specific feedback, consider other viewpoints, and respect others’ privacy.

Harassment, discriminatory language, threats, sexualized conduct, deliberate disruption, and publishing someone’s private information without permission are unacceptable in project issues, pull requests, and other project spaces.

Maintainers may edit or remove inappropriate content, close disruptive discussions, or restrict participation. Apply these measures in proportion to the conduct and its impact.

To report a concern, use a private contact method published on the maintainer’s GitHub profile. If none is available, request a private contact channel without sharing sensitive details publicly. Affected people’s privacy should be respected while concerns are reviewed.
